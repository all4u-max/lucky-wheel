How it works

This version stores the lock state in the browser with localStorage, so the wheel remains locked after refresh in the same browser unless storage is cleared.[web:16]

1. Save the file as .html and open it in a browser.
2. The default admin password is admin123.
3. Search for ADMIN_PASSWORD in the code if you want to change it.
4. The lock state is stored in this browser only. If you use another computer or clear browser storage, the state will not follow there.[web:20]
